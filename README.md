# TravelGo Frontend

A frontend-only React prototype for a college Travel Booking System demonstration.

## Requirements
- Node.js 18 or newer
- npm

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite (usually http://localhost:5173).

## Build for production
```bash
npm run build
```

## Current scope
- Premium responsive login page
- Password visibility toggle
- Basic client-side form validation and demo feedback
- No backend, database, real authentication, or payment processing

## Next steps
Add the homepage, flights, hotels, packages, booking flow, confirmation, customer bookings, and admin dashboard using mock data.
